# Cara Push ke Repository Kamu

Repository kamu:

```bash
https://github.com/BilalMaulana22/learning_basic_frontend.git
```

## Clone repo

```bash
git clone https://github.com/BilalMaulana22/learning_basic_frontend.git
```

Masuk folder:

```bash
cd learning_basic_frontend
```

---

## Tambahkan file

Buat:

* index.html
* style.css
* script.js

---

## Push ke GitHub

```bash
git add .
git commit -m "Menambahkan halaman login dasar"
git push origin main
```

Kalau branch kamu `master` gunakan:

```bash
git push origin master
```

---

## Jalankan Project

Klik dua kali `index.html`

atau kalau pakai VS Code install **Live Server** lalu klik **Go Live**.
